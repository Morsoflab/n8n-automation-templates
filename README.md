# Morsof n8n Automation Templates

  Production-minded n8n workflow templates for CRM, ERP, WhatsApp, reporting, and business process automation.

  These templates are designed as practical starting points. Review authentication, permissions, error handling, retries, logging, and data-retention requirements before using them in production.

  ## Available templates
  
  - [Webhook lead intake and validation](templates/lead-intake/)
  - [Lead intake with validation, idempotency, and Data Table storage](templates/lead-intake-data-table/)
  - CRM to ERP customer synchronization
  - Automated invoice follow-ups
  - WhatsApp customer notifications
  - E-commerce order synchronization
  - Management reporting
  - Failed-workflow alerts and recovery

  ## Security

  Never commit credentials, API keys, customer data, webhook secrets, or production exports. Use n8n credentials and environment variables for sensitive configuration.
